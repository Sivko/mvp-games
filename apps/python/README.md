# Word Similarity App

Python приложение для сравнения слов по векторной модели Word2Vec.

## Функциональность

- Загружает векторную модель из `../data/model.bin` или `../data/model.txt`
- Использует статическое исходное слово: **"слон"**
- Позволяет вводить слова в консоль для сравнения
- Вычисляет косинусное сходство между исходным словом и введенным словом
- Выводит процент соответствия на основе векторной базы данных

## Требования

- Векторная модель Gensim Word2Vec в папке `../data/`
- Файлы: `model.bin` (бинарный формат) или `model.txt` (текстовый формат)

## Запуск через Docker

### Запуск с hot reload (рекомендуется)

Для автоматической перезагрузки при изменении файлов используйте docker-compose:

```bash
docker-compose up --build
```

Или в интерактивном режиме (для ввода в консоль):

```bash
docker-compose up --build -d  # Запуск в фоне
docker-compose exec app python main.py  # Подключение к контейнеру
```

Или напрямую через docker:

```bash
docker build -t word-game-app .
docker run -it --rm \
  -v $(pwd):/app \
  -v $(pwd)/../data:/app/../data \
  word-game-app python main.py
```

**Важно:** Для интерактивного ввода используйте флаги `-it` (interactive + TTY).

### Обычный запуск (без hot reload)

```bash
docker build -t word-game-app .
docker run -it --rm \
  -v $(pwd)/../data:/app/../data \
  word-game-app python main.py
```

### Подключение к запущенному контейнеру

Если контейнер уже запущен через `docker-compose up`:

```bash
# Подключиться к контейнеру для интерактивного ввода
docker-compose exec -it app python main.py
```

Или через docker:

```bash
# Найти ID контейнера
docker ps

# Подключиться к контейнеру
docker exec -it <container_id> python main.py
```

## Использование

1. Запустите приложение через docker-compose
2. Дождитесь загрузки модели
3. Введите слово для сравнения с "слон"
4. Получите результат сходства (0.0 - 1.0) и процент соответствия
5. Введите `quit` для выхода

## Пример

```
Исходное слово: слон
Введите слово для сравнения (или 'quit' для выхода):
--------------------------------------------------
> тигр

Сходство между 'слон' и 'тигр': 0.6234
Процент соответствия: 62.34%
```
